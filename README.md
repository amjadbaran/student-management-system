> ## 🎓 Student Management System (SMS)
> 
> 
> A robust, command-line Student Management System built in Java to demonstrate clean architecture and separation of concerns. The project follows a strict MVC (Model-View-Controller) pattern integrated with a Data Access Object (DAO) layer for clean database operations.
> ### ✨ Features
> 
> 
> * **View All Records:** Retrieve and display all student entries from the database.
> * **Search Specific Student:** Look up individual students by their unique ID.
> * **Add Student:** Register new students with validation rules.
> * **Update Student:** Modify existing student records (name and program).
> * **Delete Student:** Remove student records from the database.
> 
> 
> ### 🛠️ Tech Stack
> 
> 
> * **Language:** Java
> * **Build Tool:** Apache Maven
> * **Database:** SQLite
> * **Architecture:** MVC & DAO Design Pattern
